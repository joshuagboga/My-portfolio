# Joshua Gboga — Portfolio

Personal portfolio built with HTML, Tailwind CSS (CLI v4) and vanilla JavaScript.

## Development

```bash
npm install      # first time only
npm run dev      # rebuilds dist/output.css on every change
npm run build    # minified production CSS
```

Open `index.html` with Live Server while `npm run dev` is running.

- `src/input.css` — Tailwind entry: theme colours/fonts and custom components
- `dist/output.css` — generated CSS (commit it so static hosts like Vercel work without a build step)
- `script.js` — mobile menu, active nav link, scroll reveal, typing effect, contact form
- `images/` — optimised photos and project screenshots
